## 🔓 Open-Source GitHub Projects 🌐

*Sorted by GitHub Star Count (Descending)* 🌟

- **[Dify](https://github.com/langgenius/dify)** [![Stars](https://img.shields.io/github/stars/langgenius/dify?style=social&color=white)](https://github.com/langgenius/dify/stargazers)  
  **LLMOps platform with agentic workflows**, Apache-2.0 licensed. Visual workflow builder combining LLM nodes, RAG knowledge retrieval, tools, & conditional logic. Self-hosted or Dify Cloud. 🎨

- **[Open WebUI](https://github.com/open-webui/open-webui)** [![Stars](https://img.shields.io/github/stars/open-webui/open-webui?style=social&color=white)](https://github.com/open-webui/open-webui/stargazers)  
  **Self-hosted ChatGPT-style UI**, MIT licensed. Runs offline with Ollama, OpenAI-compatible APIs, MCP servers, RAG vector databases, voice I/O, & multi-user RBAC. 🔒

- **[Flowise](https://github.com/FlowiseAI/Flowise)** [![Stars](https://img.shields.io/github/stars/FlowiseAI/Flowise?style=social&color=white)](https://github.com/FlowiseAI/Flowise/stargazers)  
  **Drag-and-drop LLM app builder**, Apache-2.0 licensed. Visual node editor for building chatbots, agents, & multi-agent conversational workflows. 🎯

- **[Coqui TTS](https://github.com/coqui-ai/TTS)** [![Stars](https://img.shields.io/github/stars/coqui-ai/TTS?style=social&color=white)](https://github.com/coqui-ai/TTS/stargazers)  
  **Deep learning toolkit for Text-to-Speech synthesis**, MPL-2.0 licensed. Powers open voice conversational AI, voice cloning, & real-time dialog engines. 🎙️

- **[AstrBot](https://github.com/AstrBotDevs/AstrBot)** [![Stars](https://img.shields.io/github/stars/AstrBotDevs/AstrBot?style=social&color=white)](https://github.com/AstrBotDevs/AstrBot/stargazers)  
  **Open-source all-in-one Agent chatbot platform**, Apache-2.0 licensed. Integrates with instant messaging apps (QQ, WeChat, Telegram, Slack, Discord) with MCP tools, agent sandboxing, & WebUI. 🤖

- **[Langchain-Chatchat](https://github.com/chatchat-space/Langchain-Chatchat)** [![Stars](https://img.shields.io/github/stars/chatchat-space/Langchain-Chatchat?style=social&color=white)](https://github.com/chatchat-space/Langchain-Chatchat/stargazers)  
  **Local knowledge RAG & conversational bot engine**, MIT licensed. Powered by LangChain & local LLMs for offline document Q&A and dialog workflows. 📚

- **[Haystack](https://github.com/deepset-ai/haystack)** [![Stars](https://img.shields.io/github/stars/deepset-ai/haystack?style=social&color=white)](https://github.com/deepset-ai/haystack/stargazers)  
  **Open-source AI framework for building NLP applications**, Apache-2.0 licensed. Production-ready pipeline orchestration for RAG, search, & conversational agents. 🌾

- **[Rasa](https://github.com/RasaHQ/rasa)** [![Stars](https://img.shields.io/github/stars/RasaHQ/rasa?style=social&color=white)](https://github.com/RasaHQ/rasa/stargazers)  
  **Enterprise open-source conversational AI framework**, Apache-2.0 licensed (core). Features business logic Flows, Automatic Conversation Repair, LLM integration, & full on-premises security compliance. 🏛️

- **[Botpress](https://github.com/botpress/botpress)** [![Stars](https://img.shields.io/github/stars/botpress/botpress?style=social&color=white)](https://github.com/botpress/botpress/stargazers)  
  **Open-source platform for building AI-powered chatbots & agents**, MIT licensed. Visual flow builder with built-in NLU, knowledge base management, & multi-channel deployment. 🎨

- **[ChatterBot](https://github.com/gunthercox/ChatterBot)** [![Stars](https://img.shields.io/github/stars/gunthercox/ChatterBot?style=social&color=white)](https://github.com/gunthercox/ChatterBot/stargazers)  
  **Machine learning dialog engine**, BSD-3-Clause licensed. Lightweight Python-native framework for training simple automated Q&A bots and dialog systems. 🐍

- **[Microsoft Bot Framework SDK](https://github.com/microsoft/botframework-sdk)** [![Stars](https://img.shields.io/github/stars/microsoft/botframework-sdk?style=social&color=white)](https://github.com/microsoft/botframework-sdk/stargazers)  
  **SDK for multi-channel bot development**, MIT licensed. Bot Builder SDK v4 (C#, Node.js) with Adaptive Dialogs, Language Generation, & Azure Bot Service integration. 🏢
